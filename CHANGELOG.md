# Changelog

All notable changes to pymdcage are documented in this file.

## 1.0.0 - 2026-11-27

- Initial production release.
- Linear iterative Markdown scanner with no runtime dependencies.
- Inline, reference, image, angle-bracket, and autolink URL inspection.
- Raw HTML, HTML comment, external image, tracking pixel, and SSRF defenses.
- Unicode Tags, zero-width, invisible, bidirectional-control, and unpaired-surrogate defenses.
- Immutable policy and result dataclasses.
- Strict, agent, and docs presets.
- `pymdcage` command-line interface for audit, sanitize, and extract-links operations.
