# Code of Conduct

## Our standard

This project is a security project. Participants are expected to be accurate, respectful, and careful with vulnerability details.

Examples of expected behavior:

- report security issues privately before public disclosure,
- discuss technical evidence rather than people,
- accept correction when a threat model or measurement is wrong,
- keep proof-of-concept material minimal and defensive.

Unacceptable behavior includes harassment, publication of another person's private data, exploitation instructions aimed at real systems, and knowingly false vulnerability claims.

Project maintainers may remove comments, close issues, or restrict participation when these expectations are violated.
